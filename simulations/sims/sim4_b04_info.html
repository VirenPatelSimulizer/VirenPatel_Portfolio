Layered Aggregates (Three Types)

Spring-based tri-particle self-organization with differential adhesion

What is Differential Adhesion?

The Differential Adhesion Hypothesis (DAH), proposed by Malcolm Steinberg in 1963, explains how cells with different adhesion strengths spontaneously sort into layered structures. Cells that stick together more strongly end up in the interior, while less adhesive cells migrate to the surface.

This simulation extends the concept to three particle types (A, B, C), each with distinct preferred distances and spring stiffnesses for every pair combination. The result is emergent shell-like structures where different species occupy distinct spatial layers.

Physics Behind the Simulation

This simulation uses a spring-based force model:

  • Spring Forces: Each particle pair experiences a spring force that pulls them toward a preferred distance. Too close = repulsion, too far = attraction.
  • Asymmetric Interactions: The preferred distance and stiffness are different for each type pair (A-A, A-B, A-C, B-B, B-C, C-C), creating a rich interaction matrix.
  • Velocity Damping: A damping factor (0.9-1.0) gradually removes kinetic energy, allowing the system to settle into stable configurations.
  • Bond Visualization: Lines connecting particles within the interaction radius reveal the network structure underlying the self-organized patterns.

Key Equations

The spring force between two particles follows Hooke's Law with preferred distance:

F = stiffness × (distance - preferredDistance)

When distance > preferredDistance, the force is attractive (pulls together). When distance < preferredDistance, the force is repulsive (pushes apart). This creates stable equilibrium configurations at the preferred spacing.

Simulation Controls

  • Particle A/B/C Count: Number of each species (10-500). Three particle types create richer layering.
  • Damping: Velocity damping factor (0.9-1.0). Lower values cause faster settling into equilibrium.
  • Interaction Radius: Range of spring forces (20-300). Controls how far particles "feel" each other.
  • Show Bonds: Toggle bond line visualization to see the connectivity network.
  • Preset Configurations: Layered Shells, Tight Clusters, Loose Lattice, Segregated, Mixed Soup, Core-Shell.

Interesting Behaviors to Observe

  • Shell Formation: With the "Layered Shells" preset, particles organize into concentric layers with one type at the core and others forming successive shells.
  • Core-Shell Structures: One particle type forms a dense core while another coats the surface, mimicking core-shell nanoparticles.
  • Segregation vs. Mixing: Compare the "Segregated" and "Mixed Soup" presets to see how interaction parameters determine whether species mix or separate.
  • Lattice Formation: The "Loose Lattice" preset demonstrates how periodic spatial arrangements can emerge from isotropic interactions.
