Spatial Evolutionary Dynamics

Grid-based agent evolution with competing survival strategies

What is Spatial Evolutionary Dynamics?

Spatial Evolutionary Dynamics is a simulation framework that models how different survival strategies compete and evolve in a spatially structured environment. Unlike particle-based simulations, this uses a discrete grid where each cell can hold at most one agent.

Agents reproduce, age, and die based on their strategy type and interactions with neighbors. Over time, emergent patterns form as different strategies compete for space and resources. This models concepts from evolutionary game theory and spatial ecology.

The Three Strategies

Each agent follows one of three distinct survival strategies:

Cooperative (Green)

Cooperative agents can only reproduce into empty adjacent cells. They never attempt takeovers, making them peaceful but potentially vulnerable to being surrounded. They thrive in stable, low-conflict environments and often form tight clusters.

Competitive (Red)

Competitive agents are aggressive. They can spawn into empty cells or attempt to take over occupied cells. Takeover success depends on relative fitness scores. High-fitness competitive agents can displace weaker neighbors, but this strategy carries risk if neighbors are stronger.

Strategic (Yellow)

Strategic agents are opportunistic. They prioritize cells that were recently vacated (freed cells) before considering other empty spaces. This allows them to quickly fill gaps left by dying agents, giving them an expansion advantage in dynamic environments.

Core Mechanics

  • Grid World: A 2D array of cells where each cell is either empty or contains exactly one agent. The grid uses toroidal wrapping (edges connect to opposite sides).
  • Moore Neighborhood: Each cell considers its 8 surrounding neighbors (including diagonals) for reproduction and interaction decisions.
  • Reproduction: Agents with reproduction probability can spawn offspring into adjacent cells. The method depends on strategy type. Offspring inherit the parent's strategy.
  • Fitness-Based Takeover: When competitive agents attempt takeover, success probability is calculated as: attacker_fitness / (attacker_fitness + defender_fitness)
  • Death: Agents die from old age (exceeding lifespan) or random death probability each tick. Dead agents leave empty cells that can be colonized.

Key Formulas

Takeover probability for competitive agents:

P(takeover) = fitness_attacker / (fitness_attacker + fitness_defender)

This means an attacker with fitness 2.0 against a defender with fitness 1.0 has a 66% chance of success. Equal fitness results in a 50/50 coin flip.

Agent lifespan calculation:

lifespan = baseLifespan + random(-10, +10)

Each agent receives a slightly randomized lifespan to prevent synchronized mass die-offs.

Simulation Controls

  • Grid Size: Dimensions of the simulation grid (e.g., 50x50 = 2500 possible cells).
  • Initial Population: Starting number of agents randomly placed on the grid.
  • Reproduction Probability: Chance per tick that an agent attempts to reproduce.
  • Death Probability: Random chance of death each tick (in addition to age-based death).
  • Base Lifespan: Average number of ticks an agent lives before dying of old age.
  • Strategy Weights: Relative probability of each strategy when spawning initial agents.

Behavior Presets

  • Balanced: Equal distribution of all three strategies for observing natural competition dynamics.
  • War: High competitive population with elevated takeover rates. Expect rapid territory changes and conflict.
  • Peace: Cooperative-dominated world with low death rates. Watch stable clusters form and grow.
  • Tactical: Strategic agents dominate, demonstrating opportunistic expansion patterns.
  • Chaos: High death and reproduction rates create a turbulent, ever-changing landscape.

Emergent Behaviors to Observe

  • Cluster Formation: Cooperative agents tend to form tight, stable groups that protect interior members.
  • Invasion Fronts: Competitive agents can carve through cooperative clusters if they build fitness advantage.
  • Gap Exploitation: Strategic agents thrive in high-death environments by quickly claiming freed cells.
  • Strategy Extinction: Under certain parameters, one strategy may completely dominate and eliminate others.
  • Dynamic Equilibrium: In balanced settings, strategies may reach a fluctuating equilibrium where no single type dominates permanently.
